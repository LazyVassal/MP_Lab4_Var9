Проект Lab4: Информационная система фитнес-клуба
Описание проекта
Учебный full-stack проект, демонстрирующий работу с базой данных SQLite через Python (FastAPI) в контейнере Docker.

Технологии:

Backend: Python 3.11, FastAPI, SQLAlchemy (ORM).
Frontend: HTML, CSS, JavaScript.
База данных: SQLite (файл club.db).
Контейнеризация: Docker, Docker Compose.
Функционал:

Управление списком клиентов (ФИО, телефон, email).
Отображение активных абонементов.
Ведение истории тренировок клиентов.
Статистика посещений.
Структура проекта
Копировать
lab4/
├── backend/        # Серверная часть (Python/FastAPI)
│   ├── app/
│   └── Dockerfile
├── frontend/       # Клиентская часть (HTML/CSS/JS)
│   ├── index.html
│   └── script.js
├── data/            # Папка для хранения файла базы данных SQLite
│   └── club.db
└── docker-compose.yml # Файл для запуска всех сервисов одной командой
 
Инструкция по запуску (через Docker)
Важно: Все команды выполняются в терминале из корневой папки проекта (lab4).

1. Установка Docker
Убедись, что на твоем ПК установлены:

Docker Engine
Docker Compose
2. Сборка и запуск контейнеров
Открой терминал, перейди в папку lab4 и выполни команду:
docker compose up --build
3. Ожидание запуска
В терминале ты увидишь логи. Дождись строки вида Uvicorn running on http://0.0.0.0:8010. Это значит, что сервер успешно запустился.

4. Открытие приложения в браузере
После запуска доступны два адреса:

Веб-интерфейс (Frontend):http://localhost:8080
Документация API (Swagger UI):http://localhost:8010/docs (Здесь можно вручную тестировать все запросы).
Остановка проекта
Чтобы остановить контейнеры, не прерывая терминал клавишами Ctrl+C, открой второй терминал, перейди в папку lab4 и выполни:
docker compose down
